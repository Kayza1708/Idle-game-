# 30-Tage-Gem-Bericht

Deterministischer Abschluss-am-Periodenende-Lauf mit Start am 1. Januar 2026. Er verwendet die echten Daily-/Weekly-/Monthly-Generatoren und Claim-Funktionen sowie die tatsächlich dadurch freigeschalteten kostenlosen Season-Belohnungen. Echtgeld, Ads, Debug-Gutschriften und Shopkäufe sind ausgeschlossen; keine Belohnung wurde verändert.

Ausgeführt mit `npx vite-node scripts/gem-income-simulator.ts`:

| Quelle | Gems |
| --- | ---: |
| Daily-Aufgaben | 360 |
| Daily-Boni | 180 |
| Weekly-Aufgaben | 300 |
| Weekly-Boni | 120 |
| Monthly-Aufgaben | 990 |
| Monthly-Bonus | 120 |
| Kostenloser Season-Pass | 1.450 |
| **Gesamt** | **3.520** |

Ansparzeit in diesem vollständigen Abschluss-Szenario: 250 Gems für Offline 12 h an Tag 7; 500 Gems für Labor 3 an Tag 7; kumulativ 750 Gems für Offline 16 h an Tag 14; kumulativ 1.750 Gems für Offline 24 h an Tag 24. Das sind reproduzierbare Simulationswerte, keine Prognose typischer Spielerabschlussquoten.
